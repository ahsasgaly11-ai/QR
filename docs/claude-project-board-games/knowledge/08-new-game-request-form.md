# نموذج طلب لعبة سبورة جديدة

انسخ هذا النموذج في محادثة جديدة داخل المشروع، واملأ ما تعرفه. ما تتركه فارغًا يقترحه Claude ثم يسألك عنه قبل البناء.

```

الوحدة والدرس:
نواتج التعلّم (٢–٤):
-
-
نمط اللعبة المفضّل (صنّف / ركّب على رسم / تعرّف على المضيء / رتّب / طابِق / اقترح أنت):
المحتوى (الفئات والعناصر، أو الرسم والخانات):
- الفئات:
- العناصر وفئة كل منها:
أخطاء شائعة عند الطلاب في هذا الدرس (تصلح مشتّتات):

```

## ماذا ستستلم
1. **ثلاث أفكار مختلفة:** لكل فكرة عالمها وآليتها ولحظتها المدهشة، وسطر عن مدى اختلافها عن الألعاب الموجودة. تختار واحدة.
2. **خطة قصيرة:** التخطيط على الشاشة، والمشاهد السينمائية، والأصوات، ونواتج التعلّم، والمحتوى النهائي، والمشتّتات. تراجعها وتوافق عليها.
3. **ملفات كاملة** في `public/<slug>/`: `index.html`، و`js/main.js`، و`js/content.js`، و`js/game.js` إن احتاجت
   اللعبة قواعد غير القالب، و`css/game.css`.
4. **قائمة الأصول** المضافة بمصادرها ورخصها، و**سطر الفهرس** لـ`src/data/board-games.ts`، و**سطرا التحويل** لـ`next.config.ts`.
5. **قائمة تجربة:** بالماوس (`?sim`)، وعلى هاتف أفقي، وفي الصف.
