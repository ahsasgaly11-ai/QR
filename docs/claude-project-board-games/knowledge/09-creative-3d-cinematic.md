# الإبداع، والأبعاد الثلاثة، والمؤثرات السينمائية والصوتية

هدف كل لعبة: **لحظة يتذكّرها الطلاب**. هذه اللحظة تكشف المفهوم العلمي ولا تشتّت عنه، وتبقى ممكنة لأيدي أطفال على سبورة في صف مضاء.

---

## ١. مولّد الأفكار (لا تكرار)
اختر عنصرًا من كل عمود، وتحقق ألّا تطابق لعبة موجودة في عنصرين من الثلاثة. الألعاب الموجودة في `src/data/board-games.ts` بالمستودع.

| العالم (القصة) | الآلية (بالبقاء أو الالتقاط والإفلات) | اللحظة المدهشة |
|---|---|---|
| غوص على اللؤلؤ في الخليج | صنّف في سلال | مجسّم ثلاثي الأبعاد يطير إلى مكانه في قوس |
| رحلة في الفضاء | ركّب على رسم أو مجسّم | المشهد يتحوّل: يومٌ يصير ليلًا، وبذرة تصير شجرة |
| مختبر عالِم صغير | رتّب تسلسلًا | انفجار جسيمات بلون الفئة |
| سوق تراثي أو مدينة حديثة | طابِق زوجين | الكاميرا تدور حول المجسّم لتكشف وجهًا خفيًّا |
| الصحراء والواحات | تعرّف على المضيء | ضوء يكشف ما تحت الماء أو داخل الجسم |
| داخل جسم الإنسان | ابنِ برجًا أو سلسلة بالعناصر الصحيحة | سلسلة تفاعلات: كل صواب يحرّك آلة كبيرة |
| آلة زمن | أنقِذ أو أطعِم: العنصر الصحيح يُنقذ شخصية | مطر قصاصات وختام سينمائي باسم الفريق |
| مملكة الحروف والأرقام | سباق فريقين، لكل فريق عالمه | مؤشّر يمتلئ ويُطلق حدثًا كبيرًا |

**طريقة العمل:**
1. اكتب ثلاث تركيبات مختلفة. لكل تركيبة سطر عن ناتج التعلّم الذي تخدمه اللحظة المدهشة.
2. استبعد ما يكرّر لعبة موجودة.
3. رشّح الأقوى تعلّمًا، لا الأجمل شكلًا فقط.

**أمثلة:**
- **«قاع الخليج»** (العلوم، الكائنات الحية): يلتقط الطلاب كائنات بحرية ثلاثية الأبعاد ويضعونها في طبقات البحر. الماء يضيء عند الصواب، ويظهر لؤلؤ في محارة كلما اكتملت طبقة.
- **«مصنع الكسور»** (الرياضيات): قطع بيتزا ثلاثية الأبعاد تُركّب في دوائر. الدائرة تكتمل وتدور ثم تخرج من الفرن.
- **«قطار الحروف»** (اللغة العربية): عربات تحمل الحروف وتُرتّب لتكوين كلمة. القطار ينطلق عبر نفق ويُنطق الصوت.

## ٢. الأبعاد الثلاثة بـ three.js داخل قيود الموقع

### الاستضافة المحلية (إلزامي)
سياسة أمان المحتوى (CSP) في الموقع تسمح بالسكربتات من الموقع نفسه فقط. لا CDN ولا روابط خارجية.
- **three.js:**
  - يُستضاف في `public/board-kit/vendor/three/` مشتركًا بين الألعاب.
  - الملفات: `three.module.min.js` و`three.core.min.js` و`LICENSE`، من حزمة npm `three`، والمشروع يعتمدها أصلًا: `node_modules/three/build/`.
  - إن لم يكن المجلد موجودًا فاذكر في التسليم أن هذه الملفات تُضاف.
- **المحمّلات الإضافية** (مثل GLTFLoader من `three/examples/jsm/`) تستورد `three` باسمه المجرّد، فأضف خريطة استيراد في `index.html`، قبل سكربت اللعبة:
  ```html
  <script type="importmap">{ "imports": { "three": "/board-kit/vendor/three/three.module.min.js" } }</script>
  ```
- النماذج والأنسجة والأصوات في مجلد اللعبة: `public/<slug>/assets/`.

### ترتيب الطبقات
```
#board (SVG)  →  لوحة WebGL شفافة  →  #hud (البطاقات والنصوص)  →  طبقة الجسيمات  →  #fx (مؤشرات الأيدي)
```
- لوحة WebGL: `pointer-events: none`، وتُدرج قبل `#hud`.
- النص العربي يبقى في HTML، لا في المشهد ثلاثي الأبعاد.
- البطاقات فوق المجسّمات تكون شفافة حيث يظهر المجسّم، وإلا بدا باهتًا خلفها.

### محاذاة العالم على وحدات المسرح (حتى تصير المجسّمات أهدافًا لليد)
اجعل المستوى z = 0 يطابق المسرح تمامًا: نقطة العالم `(x, −y, 0)` تظهر عند `(x, y)` بوحدات u.
عندها تضع المجسّمات بالأرقام نفسها التي تضع بها عناصر HTML، وتحوّلها إلى أهداف دائرية:
```js
import * as THREE from '/board-kit/vendor/three/three.module.min.js';

function alignCamera(cam, VW, VH) {          // VH = 1000 دائمًا
  const dist = VH / 2 / Math.tan(THREE.MathUtils.degToRad(cam.fov / 2));
  cam.aspect = VW / VH;
  cam.position.set(VW / 2, -VH / 2, dist);
  cam.lookAt(VW / 2, -VH / 2, 0);
  cam.updateProjectionMatrix();
  cam.updateMatrixWorld();
}
const toWorld = (x, y, z = 0) => new THREE.Vector3(x, -y, z); // z > 0 = أقرب إلى الكاميرا وأكبر
function toStage(cam, v, VW, VH) {
  const p = v.clone().project(cam);
  return { x: ((p.x + 1) / 2) * VW, y: ((1 - p.y) / 2) * VH };
}
// هدف يد يغطي المجسّم كما يظهر على المسرح:
function hitCircle(cam, obj, VW, VH, pad = 16) {
  const s = new THREE.Box3().setFromObject(obj).getBoundingSphere(new THREE.Sphere());
  const c = toStage(cam, s.center, VW, VH);
  const e = toStage(cam, s.center.clone().add(new THREE.Vector3(s.radius, 0, 0)), VW, VH);
  return { x: c.x, y: c.y, r: Math.hypot(e.x - c.x, e.y - c.y) + pad };
}
```
- استدعِ `alignCamera` في `render()` بعد حساب `VW`، ثم احسب أهداف المجسّمات في `_collectTargets()`.
- **حركات الكاميرا السينمائية** مسموحة فقط حين لا أهداف لليد:
  - في الافتتاح والختام: `targets()` تُرجع قائمة فارغة.
  - بعد انتهاء الحركة تعود الكاميرا إلى المحاذاة.
- **العنصر المحمول:** يمكن أن يكون مجسّمًا ثلاثي الأبعاد يتبع اليد. انقله في كل إطار إلى `toWorld(c.x, c.y, 90)`. تبقى `heldIcon()` هالة SVG خفيفة.

### ميزانية الأداء (تتبّع اليد يتقاسم معالج الرسوم)
- الرسم ٣٠ إطارًا في الثانية على الأكثر، ودقة البكسل ≤ 1.5، ونحو ٥٠ ألف مثلث على الأكثر في المشهد.
- لا ظلال حيّة، ولا معالجة لاحقة ثقيلة (bloom، SSAO). التوهج المطلوب: دائرة شفافة أو نسيج متدرّج.
- الأنسجة إجرائية من `<canvas>` (تدرّجات وأشرطة وبقع) أو صور صغيرة (≤ 512px).
  - النماذج GLB مضغوطة ≤ ١–٢ م.ب للعبة كلها.
- أوقف الرسم حين تُخفى الصفحة (`document.hidden`).
- جرّب على الهاتف الأفقي، فهو الأضعف.

### على السبورة
- خلفية فاتحة دائمًا، حتى للفضاء: سماء فجر أو بيج فاتح. جهاز العرض لا يصنع سوادًا في صف مضاء.
- إضاءة ناعمة: HemisphereLight مع DirectionalLight. ألوان مشبعة بتباين عالٍ مع حدود واضحة.
- **لا يكشف الشكل الإجابة:**
  - خانات بحجم واحد.
  - العنصر المحمول بلا لون فئته.

## ٣. اللغة السينمائية
| اللحظة | المدة | المكوّنات |
|---|---|---|
| **الافتتاح** | ٢–٢٫٥ ث | أشرطة عريضة تنزلق، وسطر تمهيدي، وعنوان يتّسع مع ومضة ضوء، وكاميرا تقترب، وضربة منخفضة، ثم تبدأ الموسيقى. **لا أهداف لليد أثناءه.** |
| **التغذية الراجعة للصواب** | ≤ ٠٫٨ ث | العنصر يطير إلى مكانه في قوس، وجسيمات بلون الفئة عند المكان، وحلقة تتّسع، وصوت لمعان، ونطق الاسم، ثم سطر معلومة قصير. |
| **الخطأ** | ≤ ٠٫٤ ث | اهتزاز **الطبقة المرئية** فقط (لا المسرح: الأهداف ثابتة)، وصوت منخفض لطيف، ورسالة توجيهية لا لوم فيها. بعد خطأين: إضاءة المكان الصحيح. |
| **منتصف اللعبة** | — | حدث كبير عند نصف التقدّم: تغيّر الإضاءة، أو موسيقى أسرع، أو ظهور شخصية. |
| **الختام** | ٢ ث | مطر قصاصات، وعنوان سينمائي «أحسنتم!»، واسم الفريق الفائز، ثم شاشة النتيجة. |

**قواعد السلامة والوضوح:**
- لا وميض بأكثر من ٣ مرات في الثانية. هذا قيد الصرع الحساس للضوء.
- لا يغطي أي مؤثر الأهداف أثناء اللعب.
- **تقليل الحركة:** احترم `prefers-reduced-motion` وخيار الموقع `data-motion="reduce"`. حينها: مدد أقصر، وجسيمات أقل، وبلا حركة كاميرا.
- **التأخير:** الصورة على السبورة قد تتأخر ثانية في انعكاس الشاشة (الملف 01)، فلا تعتمد على توقيت يطلب من الطالب «الآن!».

## ٤. الصوت
- **مؤثرات مُركّبة بـ Web Audio** (بلا ملفات ولا حقوق). في المحرّك: `sfx.pick/correct/wrong/back/click/win`.
  - ركّب مثلها عند الحاجة: هبوب (ضجيج عبر مرشّح متحرّك)، ولمعان (نغمات عالية متتابعة)، وضربة منخفضة (موجة جيبية تهبط).
- **موسيقى خلفية توليدية خافتة** (≈ ٥٪ من الصوت):
  - نغمة أرضية ولحن متجوّل على **مقام**: الحجاز `[0,1,4,5,7,8,10]`، أو البياتي، أو الرست، أو الخماسي.
  - مقام مختلف لكل لعبة، وإيقاع أسرع للتشويق.
  - تتوقف مع إيقاف المؤثرات في لوحة المعلّم.
- **نطق** الاسم بالعربية عند الصواب: `say()`.
- **ملفات صوت** (اختياري):
  - CC0 فقط، صغيرة (mp3 أو ogg ≤ ١٠٠ ك.ب)، في `assets/`.
  - تُشغّل بعد أول لمسة، وهذا شرط iOS.
- الصوت ينتقل مع انعكاس الشاشة إلى سمّاعة جهاز العرض.

## ٦. قائمة مراجعة اللعبة المبدعة قبل التسليم
- [ ] الفكرة لا تكرّر لعبة موجودة في عنصرين من (العالم، الآلية، اللحظة المدهشة).
- [ ] اللحظة المدهشة تكشف المفهوم، ويمكن قول ذلك في جملة.
- [ ] افتتاح وختام سينمائيان، وأثناءهما لا أهداف لليد.
- [ ] كل صواب: حركة، وجسيمات، وصوت، ونطق، ومعلومة. كل خطأ: لطيف، ويبقى العنصر في اليد، وتلميح بعد خطأين.
- [ ] الأداء: ≤ ٣٠ إطارًا في الثانية للطبقة ثلاثية الأبعاد، وأصول خفيفة، وتعمل على الهاتف الأفقي.
- [ ] خلفية فاتحة، ولا شكل أو لون يكشف الإجابة، ونسخة لتقليل الحركة.
- [ ] كل مكتبة وأصل مستضاف محليًا ومسجّل برخصته في `ASSETS.md`.
