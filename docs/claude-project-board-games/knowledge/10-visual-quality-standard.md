# معيار الجودة البصرية — تقنية «دانة الصف» و«مختبر العدسة المكبّرة» (أكتوبر ٢٠٢٦)

هذا الملف هو **المرجع الملزم لمستوى الرسوميات** في كل لعبة سبورة ثلاثية الأبعاد. مصدره ملفّان أرسلهما المعلّم مثالًا على الجودة المطلوبة:

| الملف | ما يمثّله |
|---|---|
| **«دانة الصف»** (رحلة الغوص على اللؤلؤ) | عالم ثلاثي الأبعاد كامل: سماء ومحيط وقاع بحر، ومواد فيزيائية (لؤلؤ متقزّح وصدف وذهب)، وإضاءة بيئية منعكسة، وتوهّج وتدرّج لوني سينمائي، وجسيمات، وسمات زمنية (غروب، فجر، ضحى، ليل) |
| **«مختبر العدسة المكبّرة»** | مختبر واقعي خفيف جدًا: WebGL مكتوب يدويًا بمظلِّلات خاصة، وعدسة تكبّر فعلًا (رسم المشهد في نسيج ثم تشويهه)، وظلال ناعمة، وعمق ميدان، وتفاصيل سطوح إجرائية |

**القاعدة:** كل لعبة جديدة تُقارن بهذين الملفين قبل التسليم. إن بدت أبسط منهما بوضوح (ألوان مسطّحة، مواد بلا انعكاس، مشهد بلا إضاءة أو عمق) فهي **لم تبلغ المعيار**.

> هذا الملف يتقدّم على أي قاعدة أقدم في 02 أو 09 تمنع هذه التقنيات. وقد عُدّل 02 و09 بما يوافقه.

## ١. المحرّك: three.js الكلاسيكي هو المسار الأساسي
- **المسار الأساسي («السينمائي»):** `WebGLRenderer` من `three.module.min.js` (r186.1 في `public/board-kit/vendor/three/`)، مع إضافات `examples/jsm` من النسخة نفسها. هذا ما صنع «دانة الصف»، ويعمل على كل الأجهزة ومنها الآيباد والآيفون القديمة.
- **مسموح ومطلوب:** `ShaderMaterial` بمظلِّلات GLSL خاصة (سماء، ماء، ضوء متسرّب، جسيمات)، و`EffectComposer` مع `UnrealBloomPass` و`ShaderPass` و`OutputPass`.
- **المسار البديل (WebGPU + TSL):** فقط حين تحتاج اللعبة شيئًا لا يقدّمه WebGL: جسيمات حوسبة بعشرات الآلاف، أو مجسّم Gaussian Splat. وعندها تُطبَّق المواد والإضاءة والتدرّج نفسها بمكافئاتها في TSL (`MeshPhysicalNodeMaterial`، و`PMREMGenerator`، وعقدة `bloom()`)، وتُطابَق مع أمثلة النسخة.
- **WebGL مكتوب يدويًا** (أسلوب «مختبر العدسة»): مسموح للمشاهد الصغيرة الخاصة جدًا (عدسة، مجهر، منظار) حين يكون أخفّ وأدقّ من three.js.
- **لا تخلط مسارين في صفحة واحدة**: لا `three.module.min.js` مع `three/webgpu`.

**خريطة الاستيراد للمسار السينمائي:**
```html
<script type="importmap">{ "imports": {
  "three": "/board-kit/vendor/three/three.module.min.js",
  "three/addons/": "/board-kit/vendor/three/addons/"
} }</script>
```

**ملفات `vendor/three/addons/` المطلوبة** (من `examples/jsm/` للنسخة نفسها، مع الحفاظ على المجلدات؛ نحو ٣١٠ ك.ب). **أُضيفت مع إعادة تصميم «صيّادو الجراثيم»**، فتأكد من وجودها في المستودع:
```
postprocessing/EffectComposer.js  RenderPass.js  ShaderPass.js  MaskPass.js  Pass.js  UnrealBloomPass.js  OutputPass.js
shaders/CopyShader.js  LuminosityHighPassShader.js  OutputShader.js
environments/RoomEnvironment.js
loaders/GLTFLoader.js   utils/BufferGeometryUtils.js  utils/SkeletonUtils.js   libs/meshopt_decoder.module.js
```

## ٢. المكوّنات السبعة للجودة (إلزامية في الطبقة A)

### ٢.١ إعداد المحرّك
```js
// نمط مرجعي مأخوذ من «دانة الصف» — طابقه مع أمثلة three.js r186 قبل الاستعمال
const renderer = new THREE.WebGLRenderer({ canvas, antialias: true, alpha: false, powerPreference: 'high-performance' });
renderer.outputColorSpace = THREE.SRGBColorSpace;
renderer.toneMapping = THREE.ACESFilmicToneMapping;   // أو AgXToneMapping لألوان أهدأ
renderer.toneMappingExposure = 1;                     // يتغيّر مع سمة المشهد (0.95–1.1)
canvas.addEventListener('webglcontextlost', (e) => { e.preventDefault(); lost = true; });
canvas.addEventListener('webglcontextrestored', () => { lost = false; });
```
- الكاميرا `PerspectiveCamera` بزاوية تتكيّف مع نسبة الشاشة: في «دانة» من 64° (شاشة ضيقة) إلى 48° (عريضة).
- **ملاحظة r186:** `PCFSoftShadowMap` أُزيل؛ استعمل `PCFShadowMap` ونعومة الظل من `light.shadow.radius`.

### ٢.٢ إضاءة بيئية منعكسة (أهم مكوّن)
```js
import { RoomEnvironment } from 'three/addons/environments/RoomEnvironment.js';
const pmrem = new THREE.PMREMGenerator(renderer);
scene.environment = pmrem.fromScene(new RoomEnvironment(), 0.04).texture;
scene.environmentIntensity = 0.45;                    // 0.28 تحت الماء
pmrem.dispose();
```
ثم ثلاثة أضواء فقط:
- `HemisphereLight` (سماء/أرض) بلون السمة.
- `DirectionalLight` «شمس» بقوة 2–2.8.
- `PointLight` خافت للحظة الكشف (يرتفع عند الصواب).

### ٢.٣ مواد فيزيائية لا ألوان مسطّحة
كل عنصر مهم في اللعبة `MeshPhysicalMaterial` أو `MeshStandardMaterial`، **لا** `MeshBasicMaterial` ولا تظليل كرتوني. قيم مجرّبة من «دانة الصف»:

| المادة | القيم |
|---|---|
| **لؤلؤ** | `roughness .16, clearcoat 1, clearcoatRoughness .06, iridescence .9, iridescenceIOR 1.55, iridescenceThicknessRange [220,520], sheen .6, sheenRoughness .35, envMapIntensity 1.5, emissive = اللون بقوة .05` |
| **صدف من الداخل (نَكَر)** | `roughness .28, iridescence 1, iridescenceIOR 1.9, iridescenceThicknessRange [180,720], clearcoat .5, envMapIntensity .9, side: DoubleSide` |
| **ذهب ونحاس** | `metalness 1, roughness .22–.3` بلون `#e2b25c` |
| **مينا / بلاستيك لامع** (عناصر اللعب) | `roughness .4, clearcoat .9, clearcoatRoughness .18` بلون مشبع |
| **زجاج** | في A: `transmission 1, thickness, ior 1.5, roughness .04`. في B: `transparent, opacity .35, clearcoat 1` |
| **خشب وحبال وصخر** | `MeshStandardMaterial` بـ `roughness .85–1`، و`flatShading` للصخر |
| **نماذج مصوّرة** (سمكة…) | نسيج لون + نسيج اتجاهات السطح (normal map) بصيغة WebP، و`emissiveMap` = نسيج اللون بقوة ~.2 ليبقى واضحًا على جهاز العرض |

- **أشكال ناعمة:** كرات بـ 48×32 قطعة، وصناديق بحواف مدوّرة (`ExtrudeGeometry` بـ bevel)، لا حواف حادة رخيصة.
- **تفاصيل سطوح إجرائية** (أسلوب «مختبر العدسة»): ضجيج (noise) في المظلِّل يضيف تفاوت اللون وخشونة دقيقة، بلا أنسجة.

### ٢.٤ عالم مرسوم بالمظلِّلات (لا خلفية فارغة)
المشهد عالم كامل يملأ الشاشة، لا مجسّمات طافية فوق لون واحد. أمثلة «دانة الصف»:
- **سماء** `ShaderMaterial` على قبة: تدرّج ثلاثي (أعلى، وسط، أفق)، وقرص شمس، وسحب بضجيج متعدد الطبقات (FBM)، ونجوم ليلًا. في آخر المظلِّل:
  `#include <tonemapping_fragment>` و`#include <colorspace_fragment>`.
- **محيط** بموجات Gerstner (٤ موجات) في مظلِّل الرؤوس، ولون عميق/ضحل، وانعكاس السماء.
- **تحت الماء:** ضباب `FogExp2` بلون مختلف، وأنماط ضوء متموّج (caustics) من نسيج ضجيج، وأشعة ضوء متسرّبة، وعوالق.
- **ضباب** `FogExp2` فوق الماء بكثافة ~0.004 يعطي عمقًا.
- **مختبر:** بقعة ضوء على الطاولة، وشبكة خفيفة تتلاشى بالبعد، وظلال ناعمة تحت كل جسم.

**سمات المشهد** (جدول ألوان واحد يغيّر كل شيء). من «دانة الصف»:

| السمة | أعلى السماء | الوسط | الأفق | الشمس | تعريض |
|---|---|---|---|---|---|
| الضحى | `#1763b6` | `#56a8e2` | `#d2efff` | `#fffbe8` | .95 |
| الفجر | `#20447a` | `#7fa6cf` | `#ffdcae` | `#ffe9c4` | 1 |
| الغروب | `#16123a` | `#8c3566` | `#ffa860` | `#ffc88a` | 1 |
| الليل | `#02030c` | `#091330` | `#18274f` | `#cfdcff` | 1.1 |

### ٢.٥ معالجة لاحقة سينمائية
الترتيب المعتمد في «دانة الصف»:
```js
const rt = new THREE.WebGLRenderTarget(4, 4, { type: THREE.HalfFloatType, samples: 4 }); // 4 في A على غير اللمس، و0 في B
const composer = new EffectComposer(renderer, rt);
composer.addPass(new RenderPass(scene, camera));
composer.addPass(sanitizePass);        // ShaderPass يصفّر القيم الشاذة (NaN) ويحدّها بـ 24 قبل التوهّج
const bloom = new UnrealBloomPass(new THREE.Vector2(256, 256), 0.5, 0.65, 0.86);
composer.addPass(bloom);               // strength .4–.5، radius .7، threshold .88–.92
composer.addPass(gradePass);           // ShaderPass: تظليل الأطراف .5–.75، وتلوين، وتموّج وانحراف لوني خفيف تحت الماء
composer.addPass(new OutputPass());    // التدرّج اللوني (ACES/AgX) والتحويل إلى sRGB
```
- لا تُنشأ المعالجة اللاحقة إلا إذا كان `renderer.capabilities.isWebGL2` وفيه `EXT_color_buffer_float` أو `EXT_color_buffer_half_float`؛ وإلا ارسم مباشرة.
- **جهاز العرض والخلفيات الفاتحة:** التوهّج على خلفية فاتحة يبيّض الصورة كلها (جُرّب ذلك فعلًا). في المشاهد الفاتحة اجعل العتبة ≥ 1 (في القيم الخطية قبل التدرّج) فلا يتوهّج إلا ما له `emissive` قوي، أو أوقف التوهّج واستعمل هالة مرسومة.

### ٢.٦ جسيمات وحياة دائمة
- فقاعات، وشرر، وعوالق، وغبار ضوء: `Points` بمظلِّل خاص يحسب حجم النقطة من دقة الشاشة (`uPx`).
- أسراب بـ `InstancedMesh` (حبال، أسماك، خرز).
- كل شيء يتحرك قليلًا دائمًا: موج، تمايل، دوران بطيء للعنصر المهم. المشهد لا يتجمّد أبدًا.

### ٢.٧ واجهة زجاجية وخطوط عربية حقيقية
- **خطوط:** `"Noto Kufi Arabic"` للعناوين و`"Tajawal"` للنص (رخصة OFL)، تُستضاف محليًا في `/fonts/`. أو خطوط الموقع الحالية (Baloo Bhaijaan 2 وReadex Pro وEl Messiri) بالأسلوب نفسه.
- **لوحات زجاجية:** `background: rgba(6,20,32,.78); backdrop-filter: blur(12–14px) saturate(1.2); border: 1px solid rgba(246,239,226,.17); border-radius: 18–20px; box-shadow: 0 10px 30px rgba(0,0,0,.35)`.
  - في B وC: خلفية صلبة بلا `backdrop-filter`، فهو مكلف مع لوحة WebGL على الهاتف.
- **ألوان «دانة الصف»:** `--ink #06131f`، و`--pearl #f6efe2`، و`--brass #e8bb6a`، و`--sea #37c2ba`، و`--maroon #8A173E`، و`--ok #62d9a8`، و`--warn #ffb37a`.
- **شاشة تحميل مصمّمة** (لؤلؤة تلمع، وشريط تقدّم، ورسالة من عالم اللعبة)، لا شاشة بيضاء.
- **أيقونات** SVG مرسومة بخط موحّد (`stroke-width: 2`، `stroke-linecap: round`)، وشعار صغير للعبة بتدرّج.
- **حركات CSS:** دخول ناعم، ونبض للهدف المهم، وظهور بارتداد (`cubic-bezier(.3,1.6,.5,1)`).

## ٣. تقنيات «مختبر العدسة المكبّرة» (للمشاهد العلمية الدقيقة)
- **عدسة تكبّر فعلًا:** يُرسم المشهد من موضع العدسة في نسيج (render target)، ثم يُعرض داخل دائرة العدسة مع:
  - تشويه برميلي خفيف عند الحافة (`n *= 1.0 - 0.10*rr*rr`).
  - انحراف لوني عند الأطراف (قنوات الأحمر والأخضر والأزرق بإزاحات صغيرة).
  - تعتيم الحافة ولمعة زجاج قطرية.
- **عمق ميدان (تركيز المجهر):** تمويه بـ ١٤ عيّنة على «الزاوية الذهبية» (`2.39996`)، يقلّ حين يُضبط التركيز. لحظة «الوضوح» نفسها تعلّم المفهوم.
- **ظلال ناعمة بلا خرائط ظل:** حتى ٤ «بقع» ظل (`uBlob[4]`) تُحسب في مظلِّل الأرض.
- **انعكاس بيئي مزيّف** بدالة `env(r)` في المظلِّل، وتأثير فرينل (`pow(1-dot(N,V),3)`)، ولمعة محسوبة من خشونة السطح. واقعية برخص شديد.
- **مجسّمات إجرائية:** الأشكال تُبنى بالكود (لا نماذج خارجية)، وكل رأس يحمل لونه ولمعانه وشفافيته.

## ٤. طبقات الجودة بأسلوب الملفين
الأهداف وأحجامها ومواضعها وقواعد اللعب **واحدة في كل الطبقات**؛ الذي يتغيّر هو الزينة فقط.

| البند | A — سينمائي كامل | B — قياسي | C — هادئ |
|---|---|---|---|
| المحرّك | WebGL2 + معالجة لاحقة | WebGL، المعالجة اللاحقة خفيفة أو بلا | بلا 3D |
| دقة البكسل (الحد) | ≤ 1.5 مع الكاميرا والتتبّع (2 بلا تتبّع) | ≤ 1.15 | — |
| حدّ البكسلات الكلي | ~2.6 مليون | ~1.4 مليون | — |
| التوهّج والتدرّج اللوني | نعم، MSAA 4 على غير اللمس | توهّج بثلث الدقة، بلا MSAA | — |
| طبقات الضجيج (FBM) في السماء والضوء | 4 | 3 | — |
| ظلال حيّة | ظل واحد ناعم | أقراص ظل متدرّجة | ظل CSS |
| زجاج حقيقي (transmission) | نعم | زجاج شفاف رخيص | — |
| البديل | — | — | **صور مُصيَّرة مسبقًا** من الطبقة A لكل مجسّم وللخلفية (WebP)، مع CSS. تبقى جميلة بكلفة صفر |

**منظّم الجودة** (مأخوذ من «دانة الصف»):
- يقيس معدل الإطارات أثناء الافتتاح (لا أهداف لليد).
- إن نزل عن ~26 إطارًا في الثانية مرتين متتاليتين، يخفّض أولًا دقة البكسل إلى 0.75 من حدّها، ثم ينزل طبقة.
- الطبقة المفروضة من الرابط (`?tier=`) لا يغيّرها.
- **قبل الافتتاح:** `renderer.compile(scene, camera)` مع إظهار كل المجموعات لحظة، حتى لا يتقطّع أول ظهور لمجسّم.

## ٥. التكييف مع جهاز العرض في الصف (مهم)
الملفان صُمّما بخلفيات غنية وأحيانًا داكنة. جهاز العرض في صف مضاء لا يصنع سوادًا، لذلك:
- **أثناء اللعب** استعمل سمة مضيئة (الضحى أو الفجر، أو مختبر مضاء)، وتعريضًا ≥ 1.
- **السمات الداكنة** (الليل، الأعماق، الغروب الداكن) للافتتاح والختام ولحظة الكشف فقط، أي لثوانٍ.
- **ارفع الأسود:** أدنى سطوع في الصورة ~7٪ (تمريرة أخيرة: `c = lift + c*(1-lift)`)، فلا تضيع التفاصيل الداكنة على السبورة.
- **الأهداف والنصوص** على لوحات واضحة التباين (≥ 7:1)، وحدود مضيئة حول عناصر اللعب.
- **هذا يُختبر في الصف أولًا:** صوّر السبورة بالهاتف أثناء اللعب، وقارن السمتين قبل اعتماد اللعبة.

## ٦. الصوت بمستوى الملفين
- مؤثرات قصيرة مسجّلة (MP3 ≤ ٣٠ ك.ب لكل مؤثر، CC0) للحظات المهمة (الصواب، والكشف، والفوز)، وتُضاف إلى مؤثرات `sfx` المركّبة في المحرّك.
- طبقة جوّ مستمرة من عالم اللعبة (موج، فقاعات، مختبر هادئ) خافتة جدًا.
- موسيقى على مقام (الملف 09، القسم ٧). الكل يتوقف من لوحة المعلّم، ويبدأ بعد أول لمسة (شرط iOS).
- في الموقع تُوضع الأصوات ملفات في `assets/`؛ لا Base64 داخل JavaScript، فهو يكبّر الحجم ويبطئ التحميل.

## ٨. مثال مطبَّق: «صيّادو الجراثيم» (أكتوبر ٢٠٢٦)
أول لعبة أُعيد تصميمها بهذا المعيار، ومرجع عملي للكود في `public/germ-hunters/js/`:
- `scene3d.js`: المحرّك والمعالجة اللاحقة (`RenderPass` ← `UnrealBloomPass` بعتبة 1.6 ← `OutputPass` ← رفع الأسود)، وجدار بمظلِّل، وخزائن فحص، ومصباح يتوهّج، وصور البطاقات من المجسّمات (`makeThumbs`)، ولحظة القائمة.
- `models.js`: مواد فيزيائية، وخشونة منحوتة على المعالج المركزي (ضجيج كسري، وخلايا للثقوب)، ووضع بنفسجي بلا إعادة تجميع (`setUV`).
- `germs.js`: آلاف النقاط بقيم HDR تلتقطها مرحلة التوهّج.
- **دروس من البناء:**
  - التوهّج بعتبة أقل من ~1.2 على خلفية فاتحة يبيّض الصورة كلها.
  - آلاف النقاط المضيئة المتراكبة تصير وهجًا أبيض؛ خفّف شدتها وعددها.
  - الإطار الداكن (ألمنيوم مؤكسد) يفصل الخزانة عن الجدار الفاتح.
  - خذ عيّنات السطح من الحجم النهائي للمجسّم، لا أثناء حركة ظهوره.

## ٩. قائمة المقارنة قبل التسليم
- [ ] لقطة من اللعبة في الطبقة A بجانب لقطة من «دانة الصف»: الإضاءة والمواد والعمق بالمستوى نفسه.
- [ ] إضاءة بيئية (PMREM) + تدرّج لوني (ACES/AgX) + `MeshPhysicalMaterial` للعناصر المهمة.
- [ ] عالم يملأ الشاشة بمظلِّل (سماء، ماء، مختبر…) وضباب أو عمق، لا خلفية فارغة.
- [ ] توهّج وتدرّج لوني في A، بلا تبييض للصورة على الخلفية الفاتحة.
- [ ] جسيمات وحركة دائمة خفيفة.
- [ ] خطوط عربية حقيقية، ولوحات زجاجية، وشاشة تحميل مصمّمة، وأيقونات SVG موحّدة.
- [ ] سمة مضيئة أثناء اللعب، والداكنة لثوانٍ فقط، ورفع الأسود.
- [ ] B تعمل بلا معالجة ثقيلة، وC بصور مُصيَّرة مسبقًا، والأهداف في المواضع نفسها.
- [ ] المنظّم يقيس في الافتتاح، و`compile` قبل الظهور الأول، ومعالجة فقدان سياق WebGL.
