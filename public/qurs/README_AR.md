# قرص التحدي — تطبيق ويب (PWA) للرمي بالواقع المعزز

لعبة صفّية: تثبّت الجهاز أمام القرص المعلّق، تُعرض شاشته على السبورة، يرمي الطلاب الكرات، والتطبيق يتعرف على القرص ويتابعه، يرصد الكرة ويحسب النقاط، ويعرض سؤالًا وجائزة بحسب صعوبة الخانة، مع مؤثرات ثلاثية الأبعاد فوق سطح القرص.

يعمل على iPad وiPhone (Safari) وأجهزة Android (Chrome) وحواسيب Windows/Mac، ويُثبَّت على الشاشة الرئيسية ويعمل دون إنترنت بعد أول فتح.

## التشغيل والنشر
الكاميرا لا تعمل من ملف محلي؛ يلزم رابط **https**. ثلاث طرق:

**Firebase Hosting (الأنسب مع بنيتك):**
```bash
npm i -g firebase-tools
firebase login
firebase init hosting   # اختر مشروعك، المجلد العام: . (نقطة)، لا تستخدم إعادة الكتابة إلى index
firebase deploy --only hosting
```
ملف `firebase.json` جاهز (يضبط الكاش والصلاحيات).

**GitHub Pages:** ارفع المجلد كاملًا إلى مستودع، وفعّل Pages من الفرع الرئيسي. يعمل مباشرة (لا يحتاج بناء).

**أي استضافة ثابتة:** المجلد ملفات ثابتة فقط؛ لا خادم ولا أدوات بناء.

ثم على iPad: افتح الرابط في Safari → مشاركة → «إضافة إلى الشاشة الرئيسية». يعمل بعدها بملء الشاشة ودون إنترنت.

## الاستخدام في الصف
1. ثبّت الجهاز على حامل بحيث يملأ القرص ربع الصورة على الأقل. ليس شرطًا أن يبقى ثابتًا؛ التتبع يتابع القرص.
2. «افتح الكاميرا» → يظهر الإطار الأخضر فوق القرص وتظهر شريحة «التتبع».
3. «ابدأ اللعب» والقرص فارغ من الكرات (يلتقط صورته المرجعية).
4. يرمي الطلاب؛ الكرة تُسجَّل خلال نحو عُشر ثانية من استقرارها. السؤال يظهر بعد كل كرة مؤكدة.
5. «الفريق التالي» بعد جمع الكرات. «تراجع» يلغي آخر رمية. «إنهاء اللعبة» يحفظ النتيجة في السجل.

من «المزيد»: إيقاف مؤقت، إيقاف الأسئلة، إعادة المعايرة، التقاط صورة القرص الفارغ، التسجيل باللمس (لكرة ارتدّت ولم تلتصق)، الشبكة، ملء الشاشة، المحرر.

## كيف يتعرف المحرك على القرص ويتابعه
1. عند فتح التطبيق يُحمَّل OpenCV في الخلفية (مرة واحدة، ثم من المخزن). في شاشة الكاميرا تظهر نسبة التحميل أول مرة.
2. كل إطار: تُستخرج ميزات ORB وتُطابَق مع ميزات صورة القرص المرجعية بثلاثة مقاييس؛ RANSAC يحسب الهوموغرافي ويرفض المطابقات الخاطئة. لا يعتمد على الألوان، فيعمل في الإضاءة الضعيفة ومن زوايا مائلة ومع دوران الجهاز.
3. بعد التعرف: التتبع بالتدفق البصري بين الإطارات (أسرع وأنعم من إعادة التعرف)، مع إعادة مطابقة داخل نافذة القرص كل ١٠ إطارات حتى لا ينجرف.
4. بعد ثبات القفل يلتقط المحرك صورة القرص بإضاءة الصف ويبني منها مرجعًا حيًا، فيصبح التعرف بعد أي انقطاع فوريًا.
5. الكرة: تُقوَّم صورة القرص إلى شبكة ثابتة بغض النظر عن حركة الكاميرا، وتُقارن بلقطة القرص الفارغ مع تعويض الإضاءة؛ تُسجَّل الكرة فقط بعد استقرارها عدة إطارات وبشكل مستدير وبحجم كرة، ولا يُحكم أثناء الاهتزاز أو مرور شخص أو تبدّل الإضاءة (بوابة الهدوء). لذلك لا تظهر انفجارات أو أسئلة دون رمية.

المتطلبات: Safari على iOS 15 فأحدث أو Chrome/Edge/Firefox حديث (WebAssembly مع bulk-memory). على الأجهزة الأقدم يعمل المحرك الاحتياطي تلقائيًا ويُعلم المستخدم بذلك.

## المزامنة السحابية (اختيارية)
في `config.js` ضع إعداد Firebase و`schoolId`. تُحفظ الإعدادات والنتائج في Firestore تحت `schools/<schoolId>/…` إضافة إلى الحفظ المحلي. قواعد الأمان في Firestore مسؤوليتك (اقترح السماح بالقراءة والكتابة للمستخدمين المسجلين في مدرستك فقط).

## الاختبارات المنفَّذة (آليًا على صورة القرص الحقيقية، المحرك ٤)
| الحالة | النتيجة |
|---|---|
| تدفّق اللعبة: إصابة → سؤال → مكافأة → إنهاء → حفظ النتيجة | يعمل، بلا تمرير أفقي |
| كاميرا ثابتة | قفل خلال ٠٫٧ ث (يشمل تهيئة المحرك)، ٢٥/٢٥ |
| اهتزاز ودوران وتكبير مستمر (٨ ث بلا كرات ثم رمي) | صفر رميات وهمية، ٢٥/٢٥ |
| هاتف عمودي مع اهتزاز، ومحاكاة يد ترتجف مع ضجيج وتعريض متغير | صفر رميات وهمية، ٢٥/٢٥ |
| ثلاث رميات متتالية خلال ثانية والأسئلة تعمل | ٣/٣ أسئلة بالترتيب |
| كرات بلون الخانة نفسها | ٢٥/٢٥ |
| منظور مائل من اليسار، وميل شديد نحو ٦٠° | ٢٥/٢٥، ٢٥/٢٥ |
| قرص صغير في الصورة (١٢٪ من العرض)، قرص بعيد ومعتم | قفل خلال ٠٫٧ ث، ٣/٣ |
| إضاءة ٣٥٪ فقط، صورة ضبابية | ٢٥/٢٥، ٣/٣ |
| الجهاز مدوَّر ٩٠° (عمودي) | ٣/٣ |
| نصف القرص خارج الإطار | ٢/٢ |
| مشي مستمر بالكاميرا (إزاحة ودوران وتكبير) طوال اللعب | صفر رميات وهمية، ٢٥/٢٥ |
| شخص يمر أمام القرص ٧ ث، ويد تدخل لجمع الكرات | صفر رميات وهمية، لا يُفقد التتبع، ٨/٨ بعدها |
| دقة موضع الكرة (٢٤ موضعًا، أمامي ومقطوع ومائل) | متوسط الخطأ ٠٫٨٪ من نصف القطر، أقصى ٢٫٢٪ (٥٫٥٪ في الميل الشديد) |
| تشغيل متواصل دقيقتين مع حركة ورميات | ٣٠/٣٠، زمن الإطار ثابت ٢٠–٣٠ م.ث، لا تسرّب ذاكرة |

تشغيل الاختبارات: `pip install playwright pillow numpy && playwright install chromium && python3 tests/test_pwa.py && python3 tests/stress.py`

**القياسات أعلاه على Chromium بلا واجهة.** على الأجهزة الحقيقية تختلف السرعة؛ شريحة «معلومات التتبع» من قائمة «المزيد» تعرض الدقة والزمن وعدد نقاط التتبع.

## ما بعد النشر: مسار الدقة
1. جمع ٣٠٠ إلى ٨٠٠ إطار من الصف عبر «جمع بيانات التدريب».
2. تدريب YOLO11n وتصديره (training/).
3. تفعيل `BALL_MODEL_URL` ووضع `onnxruntime-web` في `vendor/ort/`.
