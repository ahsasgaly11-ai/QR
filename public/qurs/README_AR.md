# قرص التحدي — تطبيق ويب (PWA) للرمي بالواقع المعزز

لعبة صفّية: تثبّت الجهاز أمام القرص المعلّق، تُعرض شاشته على السبورة، يرمي الطلاب الكرات، والتطبيق يتعرف على القرص ويتابعه، يرصد الكرة ويحسب النقاط، ويعرض سؤالًا وجائزة بحسب صعوبة الخانة، مع مؤثرات ثلاثية الأبعاد فوق سطح القرص.

يعمل على iPad وiPhone (Safari) وأجهزة Android (Chrome) وحواسيب Windows/Mac، ويُثبَّت على الشاشة الرئيسية ويعمل دون إنترنت بعد أول فتح.

## التشغيل والنشر
الكاميرا لا تعمل من ملف محلي؛ يلزم رابط **https**. ثلاث طرق:

**Firebase Hosting (الأنسب مع بنيتك):**
```bash
npm i -g firebase-tools
firebase login
firebase init hosting   # اختر مشروعك، المجلد العام: . (نقطة)، لا تستخدم إعادة الكتابة إلى index
firebase deploy --only hosting
```
ملف `firebase.json` جاهز (يضبط الكاش والصلاحيات).

**GitHub Pages:** ارفع المجلد كاملًا إلى مستودع، وفعّل Pages من الفرع الرئيسي. يعمل مباشرة (لا يحتاج بناء).

**أي استضافة ثابتة:** المجلد ملفات ثابتة فقط؛ لا خادم ولا أدوات بناء.

ثم على iPad: افتح الرابط في Safari → مشاركة → «إضافة إلى الشاشة الرئيسية». يعمل بعدها بملء الشاشة ودون إنترنت.

## الاستخدام في الصف
1. ثبّت الجهاز على حامل بحيث يملأ القرص ربع الصورة على الأقل. ليس شرطًا أن يبقى ثابتًا؛ التتبع يتابع القرص.
2. «افتح الكاميرا» → يظهر الإطار الأخضر فوق القرص وتظهر شريحة «التتبع».
3. «ابدأ اللعب» والقرص فارغ من الكرات (يلتقط صورته المرجعية).
4. يرمي الطلاب؛ الكرة تُسجَّل خلال نحو عُشر ثانية من استقرارها. السؤال يظهر بعد كل كرة مؤكدة.
5. «الفريق التالي» بعد جمع الكرات. «تراجع» يلغي آخر رمية. «إنهاء اللعبة» يحفظ النتيجة في السجل.

من «المزيد»: إيقاف مؤقت، إيقاف الأسئلة، إعادة المعايرة، التقاط صورة القرص الفارغ، التسجيل باللمس (لكرة ارتدّت ولم تلتصق)، الشبكة، ملء الشاشة، المحرر.

## البنية
```
index.html                 الهيكل والشاشات
css/app.css                التصميم (RTL، داكن، شاشات كبيرة وصغيرة، عمودي وأفقي)
js/main.js                 الربط: الكاميرا ↔ عامل الرؤية ↔ المشهد ↔ اللعبة ↔ الواجهة، جودة تكيفية
js/vision/worker.js        عامل الرؤية (خيط مستقل): كشف القرص بالألوان، تتبّع بالحواف دون البكسل (غاوس-نيوتن)،
                           معايرة ذاتية لأنصاف الأقطار، رصد طيران الكرة واستقرارها، مركز دون البكسل، تعلّم لون الكرة،
                           تقدير وضعية الكاميرا ثلاثية الأبعاد من الهوموغرافي
js/vision/camera.js        getUserMedia بدقة 1080p/60fps، requestVideoFrameCallback، ضخ الإطارات بضغط خلفي، المشهد التجريبي
js/vision/geometry.js      هندسة القرص والخانات والتحويلات
js/vision/ball-onnx.js     كاشف الكرة بالتعلّم الآلي (ONNX Runtime Web) — يُفعَّل بعد التدريب
js/render/arscene.js       Three.js: كاميرا من الوضعية الحقيقية، جسيمات بظلال على القرص، حلقات ترتفع، نصوص، برق، توهج الخانة، شبكة
js/game/state.js           آلة حالات اللعبة: فرق، أدوار، نقاط، أسئلة، جوائز، تراجع، نتائج
js/game/audio.js           Web Audio + مؤثرات mp3، يعمل على iOS مع الصامت
js/content/store.js        IndexedDB: الإعدادات، الأسئلة، سجل النتائج، عينات التدريب
js/content/firebase.js     مزامنة اختيارية مع Firestore (config.js)
js/ui/editor.js            محرر الأسئلة والجوائز لكل خانة ومستوى، استيراد/تصدير
js/ui/collect.js           جمع بيانات التدريب ووسمها وتصديرها
sw.js / manifest.webmanifest   PWA: تخزين كامل للعمل دون إنترنت، تثبيت على الشاشة
vendor/three.module.min.js Three.js r170 (MIT)
training/                  تحضير البيانات وتدريب YOLO وتصديره (راجع training/README_AR.md)
tests/test_pwa.py          اختبار آلي كامل (Playwright)
```
لا توجد أدوات بناء: وحدات ES أصلية و`importmap`. أي تعديل يُنشر مباشرة.

## المزامنة السحابية (اختيارية)
في `config.js` ضع إعداد Firebase و`schoolId`. تُحفظ الإعدادات والنتائج في Firestore تحت `schools/<schoolId>/…` إضافة إلى الحفظ المحلي. قواعد الأمان في Firestore مسؤوليتك (اقترح السماح بالقراءة والكتابة للمستخدمين المسجلين في مدرستك فقط).

## الاختبارات المنفَّذة (آليًا على صورة القرص الحقيقية)
| الحالة | النتيجة |
|---|---|
| تدفّق اللعبة: إصابة → سؤال → مكافأة → إنهاء → حفظ النتيجة | يعمل، بلا تمرير أفقي |
| كاميرا ثابتة | التعرف خلال ٠٫٠٥ ث، ٢٥/٢٥، خطأ موقع ٤٪ |
| اهتزاز ودوران وتكبير مستمر (٨ ث بلا كرات ثم رمي) | صفر رميات وهمية، ٢٥/٢٥، خطأ موقع ٣٪ |
| هاتف عمودي مع اهتزاز | ٢٥/٢٥، خطأ موقع أقل من ١٪ |
| منظور مائل من اليسار | ٢٥/٢٥ |
| ميل شديد نحو ٦٠° | ٢٤/٢٥ |

تشغيل الاختبار: `pip install playwright pillow numpy && playwright install chromium && python3 tests/test_pwa.py`

**لم يُختبر بكاميرا حقيقية داخل الصف.** أول حصة ستحدد ضبط الحساسية ولون الكرات والإضاءة.

## ما بعد النشر: مسار الدقة
1. جمع ٣٠٠ إلى ٨٠٠ إطار من الصف عبر «جمع بيانات التدريب».
2. تدريب YOLO11n وتصديره (training/).
3. تفعيل `BALL_MODEL_URL` ووضع `onnxruntime-web` في `vendor/ort/`.
