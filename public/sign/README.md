# قاموس لغة الإشارة القطرية (أصول موثّقة)

هذا المجلد هو **مصدر الإشارات** الذي يقرأ منه محرّك الترجمة الإشارية التلقائي
في المنصّة. المحرّك جاهز ويتعرّف على كل نشاط تلقائيًّا (يقرأ عنوان النشاط
ووصفه ويعرضهما إشارةً إشارة)، لكنه **لا يعرض أي يد ملفّقة**: الإشارات البصرية
تُحمَّل حصريًّا من الأصول الموثّقة التي تضعها الجهة المختصّة هنا.

> المصدر المعتمد للإشارة القطرية: **مركز مدى (Mada)** ودوريّة **Nafath**.
> تُوضَع الإشارات الصحيحة فقط — الإشارة الخاطئة أسوأ من غيابها للطالب الأصمّ.

## كيف تعمل المطابقة

لكل كلمة في نصّ النشاط:

1. **إشارة كلمة كاملة** إن وُجدت في `words` — تُعرَض إشارةً واحدة (الأدقّ).
2. وإلا **تُهجّى** الكلمة حرفًا حرفًا من إشارات الأبجدية في `letters`.
3. وما لا تتوفّر له إشارة بعد يُعرَض **نصًّا واضحًا** مؤقتًا، ويظهر تنبيه صادق.

## بنية `manifest.json`

```json
{
  "version": 1,
  "words": {
    "علوم": { "video": "words/uloom.mp4", "gloss": "علوم" },
    "ماء":  { "img": "words/maa.png" }
  },
  "letters": {
    "ا": { "img": "letters/alef.png" },
    "ب": { "video": "letters/baa.mp4" }
  }
}
```

- **مفاتيح `words`**: تُطبَّع تلقائيًّا (تُزال التشكيلات، وتُوحَّد الهمزات
  `أ إ آ ← ا`، و`ى ← ي`، و`ة ← ه`)، فاكتب المفتاح بصورته البسيطة.
- **مفاتيح `letters`**: حرف عربي واحد. يكفي وضع الحروف الأساسية (٢٨ حرفًا).
- **`video` / `img`**: مسار نسبيّ داخل `/public/sign/` (مثل `letters/baa.mp4`)
  أو رابط مطلق. عند وجود الاثنين يُقدَّم المقطع. `gloss` تسمية اختيارية.
- الصيغ المدعومة: صور (png/jpg/svg/webp) أو مقاطع (mp4/webm).

## الإضافة

1. ضع ملفات الإشارات في `public/sign/letters/` و`public/sign/words/`.
2. سجّل كل ملفّ في `manifest.json` كما بالأعلى.
3. لا حاجة لأي تعديل في الكود — يلتقط المحرّك الأصول الجديدة تلقائيًّا.

## ملاحظة مهمّة

تهجئة الأحرف (الأبجدية الإشارية) **ليست بديلًا كاملًا** عن لغة الإشارة الجُمَلية
(التي لها إشارات ونحو وتعبيرات وجه خاصّة). كلّما زادت إشارات الكلمات الكاملة في
`words` تحسّنت الترجمة. أضِف مقطع شرح بشريًّا كاملًا لكل نشاط من لوحة الإدارة
(حقل «مقطع لغة الإشارة») حين يتوفّر — فهو الأدقّ ويظهر في تبويب «فيديو الشرح».
