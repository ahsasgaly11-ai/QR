# Firebase Studio

This is a NextJS starter in Firebase Studio.

To get started, take a look at src/app/page.tsx.

## مجسمات 3D من Tripo Studio

لتوليد وتنزيل مجسمات تعليمية ثلاثية الأبعاد (عضلات وتشريح) إلى مجلد `models/`:

```bash
npm run tripo -- --list-presets
npm run tripo -- --preset arm-muscles
```

التفاصيل في [docs/tripo-3d-models.md](docs/tripo-3d-models.md).
