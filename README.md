# منصة مناهج قطر التفاعلية 🇶🇦

منصة تعليمية تفاعلية لمناهج **دولة قطر** — تجمع التجارب العملية والمحاكاة
ثلاثية الأبعاد والأسئلة والألعاب التعليمية بصيغة **HTML**، ويمكن للزوّار
تجربتها مباشرة من المتصفّح أو تحميلها للعمل دون اتصال، مع متابعة حيّة لعدد
الزوّار والمشاهدات والتنزيلات.

صُمّمت الواجهة مستوحاةً من هوية **وزارة التربية والتعليم والتعليم العالي**
(اللون العنّابي + الذهبي)، ومن شكل كتاب العلوم للمستوى الثالث ومجسّم المها
العربي، مع لمسات ثلاثية الأبعاد وحركات سينمائية.

---

## ✨ أبرز المزايا

- **تصفّح هرمي للمناهج:** المادة ← المستوى ← الوحدة ← الدرس ← الأنشطة (يدعم
  أكثر من نشاط في الدرس الواحد).
- **أربعة أنواع من الأنشطة:** تجارب عملية، محاكاة، أسئلة تفاعلية، ألعاب تعليمية.
- **تجربة مباشرة أو تحميل:** تشغيل النشاط داخل المتصفّح (iframe آمن) مع أزرار
  ملء الشاشة والتحميل والفتح في نافذة مستقلة.
- **إحصاءات حيّة:** زوّار الموقع، مشاهدات وتنزيلات كل نشاط، ولوحة إحصاءات
  بمخطّطات وجداول.
- **رفع الأنشطة:** صفحة إدارية لرفع ملف HTML وتنظيمه حسب المادة/الوحدة/الدرس.
- **قابل للتوسّع:** إضافة مواد ومستويات ووحدات ودروس جديدة بسهولة (العلوم
  جاهزة، والرياضيات واللغة العربية مهيّأتان للإضافة).
- **تصميم عصري:** كتاب ثلاثي الأبعاد، حركات ظهور سينمائية، وضع RTL كامل،
  متجاوب مع الجوال، ويحترم `prefers-reduced-motion`.

## 🧱 التقنيات

| الطبقة | التقنية |
|---|---|
| الإطار | Next.js 15 (App Router) + React 19 |
| التنسيق | Tailwind CSS + متغيّرات تصميم مخصّصة |
| الأيقونات | lucide-react |
| البيانات والتخزين (اختياري) | Firebase Firestore + Storage |
| الاستضافة | Firebase App Hosting |

## 🚀 التشغيل محليًا

```bash
npm install
npm run dev      # وضع التطوير على http://localhost:3000
# أو
npm run build && npm run start
```

> المنصّة تعمل مباشرةً في **«وضع العرض»** بمحتوى مبدئي وعدّادات محلية
> (localStorage) دون الحاجة لأي إعداد.

## 🔥 تفعيل Firebase (اختياري — للرفع والعدّادات المشتركة)

انسخ `.env.example` إلى `.env.local` واملأ قيم مشروعك:

```bash
NEXT_PUBLIC_FIREBASE_API_KEY=...
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=...
NEXT_PUBLIC_FIREBASE_PROJECT_ID=...
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=...
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=...
NEXT_PUBLIC_FIREBASE_APP_ID=...
```

ثم انشر قواعد الأمان:

```bash
firebase deploy --only firestore:rules,storage
```

عند التفعيل:
- **الأنشطة المرفوعة** تُحفظ في مجموعة Firestore باسم `activities`، وملفاتها في
  Firebase Storage تحت `activities/**`.
- **العدّادات** (`stats/site` و`activityStats/{id}`) تُصبح مشتركة بين جميع
  الزوّار عبر عمليات `increment` الذرّية.
- تُستخدم **المصادقة المجهولة** (Anonymous Auth) تلقائيًا عند الرفع لتلبية
  قواعد الأمان — فعّلها من Firebase Console ← Authentication ← Sign-in method.

> **ملاحظة أمنية:** قواعد `activities` و`storage` الحالية تسمح بالكتابة لأي
> جلسة موثّقة لتسهيل التجربة. في الإنتاج قيّد الكتابة على المشرفين عبر
> `request.auth.token.admin == true` (راجع التعليقات داخل `firestore.rules`
> و`storage.rules`).

## 📁 بنية المشروع

```
src/
  app/
    layout.tsx            # التخطيط الجذري (RTL، الخطوط، الترويسة/التذييل)
    page.tsx              # الصفحة الرئيسية (الكتاب ثلاثي الأبعاد + الأقسام)
    browse/               # تصفّح المواد
    subject/[subjectId]/  # وحدات ودروس المادة
    play/[activityId]/    # مشغّل النشاط + الإحصاءات
    admin/                # رفع نشاط جديد
    dashboard/            # لوحة الإحصاءات
  components/             # مكوّنات الواجهة (الكتاب 3D، المها، البطاقات…)
  data/curriculum.ts      # بنية المنهج والأنشطة المبدئية (seed)
  lib/
    firebase.ts           # تهيئة Firebase (اختيارية/آمنة)
    content.ts            # دمج المحتوى المبدئي مع المرفوع
    stats.ts              # خدمة العدّادات (Firestore + fallback محلي)
    types.ts              # نماذج البيانات
public/
  games/                  # ملفات الأنشطة (HTML قائمة بذاتها)
  images/                 # شعار الوزارة والصور
```

## ➕ إضافة نشاط أو منهج جديد

**عبر الواجهة:** افتح `/admin`، اختر المادة/الوحدة/الدرس وارفع ملف HTML.
- مع Firebase: يُرفع مباشرةً ويظهر فورًا.
- بدون Firebase: تظهر لك تعليمات + كائن بيانات جاهز للصق في الكود.

**عبر الكود:** أضف ملفك إلى `public/games/`، ثم أضف عنصرًا إلى
`SEED_ACTIVITIES` في `src/data/curriculum.ts`. لإضافة مادة/مستوى/وحدة/درس
جديد، عدّل مصفوفة `SUBJECTS` في الملف نفسه.
